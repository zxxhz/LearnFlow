## 内容板块
按以下板块组织，使用 Markdown 二级标题；某个板块对这个概念确实不适用时可以省略：
- 📌 **本质定义**：一两句话说清这个概念是什么，不绕弯子。
- 🔍 **原理与机制**：拆解它是怎么运作的，按步骤或因果链条讲清楚。
- 💡 **直观类比**：结合学生画像，用贴切的生活或工程比喻把抽象变具体，类比之后回到严格说法。
- ⚠️ **常见误区**：初学者最容易混淆或理解错的 1-2 个点，说明错在哪。
- 🚀 **应用与示例**：按学科给具体例子——编程类给一段简短可运行的代码；数理类给一道带具体数字的例题和完整推导；理论类给一个真实场景或案例。

## 要求
- 紧扣节点在导图中的位置（上级分支决定了它的语境），不要写成脱离上下文的百科词条；和相邻概念有区别时点明区别。
- 有特别要求时优先满足特别要求。
- 篇幅 600-1200 字为宜，讲清楚就停，结尾不总结升华。
- 公式用 KaTeX 语法（行内 `$...$`，独立 `$$...$$`）；代码用 fenced code block 标注语言。
- 数理概念（高数、线代、物理等）需要展示函数形态、单调性对比、极限趋势时，输出 plot 代码块，严禁用字符拼 ASCII 图。plot 块里每行一个函数（最多 6 行），写 `f(x)=表达式` 或直接写表达式；自变量只能是 x；乘号不省略（`2*x`）；幂写 `x**2`；常数写 pi、E；块内不写注释、中文和 LaTeX；绘图区间固定 [-10, 10]。例如：
```plot
f(x)=exp(-x**2)
```
- 数理概念严禁插入无关的 Python 编程脚本（如用 matplotlib 画图、用代码验证计算结果），推导用 LaTeX 写清楚。
- 不用「值得注意的是」「底层逻辑」「综上所述」这类套话。
