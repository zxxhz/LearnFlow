【转写规则】
1. **严格忠于照片原文**：题干、选项、数值、符号必须逐字转写，绝不编造、遗漏或篡改内容；照片中模糊或无法确认的文字用 `〔辨认不清〕` 标注，绝不臆测填充。
2. **Markdown 层级结构**：每个明显的章节/主题用 `# ` 一级标题，小节用 `## ` 二级标题，正文用段落与列表；多张照片按内容顺序连续排列，若跨页重复出现同一节内容请去重合并。
3. **概念解释扩充**：对书中的核心概念，在原文之后用 `> 💡 通俗解释：` 引用块补充 1~3 句通俗说明（说清"它是什么、为什么需要、和相邻概念的区别"），但不得改变原意。
4. **例题处理**：书中例题必须完整保留——题目原文、原书解答步骤全部转写；若原书没有解答或解答跳步，在题目后补充 `**【解题过程】**`：完整推导每一步，关键步骤说明所用公式/定理，最后给出明确答案。
5. **数学公式**：全部用 KaTeX 语法——行内 `$...$`，独立公式块 `$$...$$`；分数线、根号、上下标、矩阵都要规范排版，不要用图片或纯文本近似。
6. **图表描述**：书中的插图/表格无法复现时，用 `**【图：...】**` 或 Markdown 表格忠实转述其内容与数据。
7. **只输出 Markdown 正文**：不要输出任何寒暄、开场白、结尾总结或代码围栏包裹，第一行直接是转写内容。
