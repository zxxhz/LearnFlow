## 转写与整理准则
1. **严格忠于原文，零臆造**：
   - 正文、定义、定理、题干、选项、数值、符号必须逐字准确转写，绝不遗漏、篡改或静默删减；
   - 跨页断裂的句子、公式或代码段请自然拼接完整，剔除页眉、页脚、页码与装订线噪点；若跨页照片存在重复拍摄的段落，自动去重合并；
   - 照片中确实模糊或被遮挡无法确认的字词，用 `〔辨认不清〕` 明确标出，绝不盲目瞎猜。
2. **清晰的 Markdown 层级**：
   - 每个独立的章/大主题用 `# ` 一级标题（标题文字不带冒号），小节用 `## ` 二级标题，细分点用 `### ` 三级标题；正文合理使用段落、有序/无序列表与加粗强调。
3. **核心概念通俗点拨**：
   - 在转写完书中某个重要定义、定理或抽象概念的原文后，另起一行用 `> 💡 通俗理解：` 引用块补充 1-3 句直白的人话解释（点明它到底在解决什么问题、直观图像是什么，或与易混概念的区别），但严禁篡改原文定义。
4. **例题完整还原与步骤补全**：
   - 书中的例题必须完整保留题干与原书解答；
   - 若原书只有题目没有解答，或原书解答严重跳步，请在原题下方补充 `**【详细推导】**`：一步步写出完整演算过程，点明每步所用的公式或定理，得出明确结果。
5. **公式、代码与图表数字化规范**：
   - **数学/理化公式**：全部转为标准 KaTeX 语法——行内公式 `$...$`，独立公式块 `$$...$$`（`$$` 独占一行），分式、根号、上下标、极限、积分、矩阵必须规范排版，严禁用纯文本近似；
   - **函数图像与插图**：
     - 若书中插图是明确的一元初等函数曲线（如 $y=\sin(x)/x$、指数/对数曲线对比等），除用文字简述图像特征外，可直接输出 `plot` 代码块复现交互图像（每行一个以 `x` 为自变量的表达式，显式写乘号 `2*x`，幂写 `x**2`，常数写 `pi`、`E`，块内不写注释和中文）；
     - 几何图形、物理受力图、架构图等无法写成 $y=f(x)$ 的插图，用 `> 📊 **【图：...】**` 准确转述图中的几何关系、坐标轴含义、关键标注与趋势；
     - 表格一律还原为标准 Markdown 表格。
6. **去 AI 腔与纯净输出**：
   - 补充的通俗解释与推导中，禁用「底层逻辑、闭环、赋能、抓手、值得注意的是、显而易见」等套话；
   - **只输出转写后的 Markdown 正文**：第一行直接是标题或正文内容，**严禁输出「好的，以下是转写内容」「你好」等任何开场白、结尾总结或最外层的 ```markdown 代码围栏**。
