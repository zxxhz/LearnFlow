## 难度递进
- 第 1 关：直接检验对核心概念或基本用法的理解，学完教材就能做出来；
- 中间关卡：需要把概念用到稍有变化的情境中；
- 最后一关：综合运用，或处理边界情况、易错情况。
- 每关考查点不重复，题目之间不要只是换个数字。

## 各题型规范（只输出上面学科要求允许的 kind）

1. **代码关（kind = "code"）**
   - task：具体情境下的编码任务，写清输入数据（直接写在代码里）和输出格式；
   - 严禁从标准输入读取（不允许 input() / std::cin），不用随机数、当前时间、文件、网络，输出必须完全确定；
   - language：填 [[LANGUAGE]]；
   - hints：2-3 条渐进提示，第 1 条指向要用的核心概念，第 2 条点拨关键思路，第 3 条（可选）提示易错细节，不要直接给代码；
   - expected_output：参考实现运行后的完整标准输出，逐字符精确（含空格和换行）；
   - reference_code：完整可运行的参考实现，运行结果必须与 expected_output 完全一致。

2. **数学计算关（kind = "math"）**
   - task：具体的化简、求导、求极限、积分或计算任务，题目中的公式用 LaTeX（`$...$`）；题干末尾用一句话提示作答格式（如「请用 x**2 表示平方，用 exp(x) 表示 e^x」）；
   - expected_output：标准答案，写成**单个** SymPy 表达式，系统会做代数等价判题：
     - 只能用变量 x y z t a b c n，常数写 pi、E；
     - 乘号不省略（`2*x`），幂写 `**`；
     - 可用函数：sin cos tan asin acos atan exp log sqrt Abs factorial 等；
     - 不要写等号、不等式、区间、集合、「或」、中文和 LaTeX；
     - 所以要设计成答案唯一的题目：多解方程、求取值范围这类答案无法写成单个表达式的题不要出；求积分时固定积分常数为 0 或改为定积分。
   - reference_answer：完整解题步骤（用 LaTeX 写推导）；
   - hints：1-2 条，提示要用的公式或第一步怎么做。

3. **单选题（kind = "choice"）**
   - task：题干；
   - options：4 个选项文本（不带「A.」前缀），长度和风格尽量接近，不让学生靠排除法猜；
   - answer：正确选项字母（"A" / "B" / "C" / "D"），正确答案的位置要随机分布；
   - 干扰项必须来自真实的常见误解，不要放明显荒谬的选项。

4. **填空题（kind = "fill"）**
   - task：题干中空位用 ______ 标出，每题只设一个空；
   - answer：所有可接受答案的数组，同义说法、等价写法都列上（如 `["重载", "函数重载"]`、`["1/2", "0.5"]`）。

5. **概念短答题（kind = "concept"）**
   - task：设计一个具体场景来提问，要求学生用自己的话回答 1-2 句，不要考死记硬背的定义原文；
   - reference_answer：评分要点，列出 2-3 个必须提到的关键点。
