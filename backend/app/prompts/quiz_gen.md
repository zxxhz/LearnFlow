## 命题总则
- 共命制 [[TOTAL]] 道题，覆盖上方列出的每一个知识点（每个知识点至少 1 道，题量在各知识点间均匀分配）。
- 每道题必须用 `kp_index` 准确标注其归属的知识点序号（从 `1` 开始的整数，严格对应上方「### 知识点 N」的编号）。
- 重在检验概念辨析、机制理解与实际推算，**不出纯靠死记硬背教材原句字面意思的题**。
- 仅限以下三种可自动判卷题型，且**严格按课程属性分配**：
  - **编程开发类课程**：综合使用 `"choice"`（单选）、`"fill"`（填空）、`"code"`（代码补全），其中代码补全题占 1-2 道；
  - **非编程类课程**（高等数学、线性代数、大学物理等数理课，以及网络协议、法律、经济等理论课）：**只允许出 `"choice"`（单选）和 `"fill"`（填空），绝对禁止出 `"code"` 代码题**。数理课的单选题和填空题应侧重公式运用、性质辨析与具体数值计算（公式用标准 KaTeX `$...$`）。

## 各题型细则

### 1. 单选题（`kind = "choice"`）
- `options`：固定为 4 个选项文本的数组（**严禁带 `A.`、`B.` 等前导字母**），四个选项的长度和句式保持均衡；
- `answer`：填正确选项字母（`"A"` / `"B"` / `"C"` / `"D"`），正确答案在 A/B/C/D 中均匀随机分布；
- 干扰项必须具有迷惑性，切中初学者常见的概念混淆、符号漏看或边界遗漏。

### 2. 填空题（`kind = "fill"`）
- `task`：在题干关键处用 `______` 标出唯一空位（每题只设一个空，答案应为明确的术语、数字、表达式或复杂度）；
- `answer`：填所有可接受等价答案的**字符串数组**，务必覆盖常见同义写法、大小写、分数与小数等价形式（如 `["1/2", "0.5"]`、`["O(n)", "o(n)", "线性时间"]`）。

### 3. 代码补全题（`kind = "code"`，仅限编程类课程）
- `language`：固定填 `[[LANGUAGE]]`；
- 单文件只依赖标准库，**严禁从标准输入读取（禁用 `input()` / `std::cin`）**，禁止使用随机数、时间、文件或网络，输出必须完全确定；
- `skeleton_code`：给出完整可运行的程序框架，仅将最核心的 1-2 行算法逻辑挖空，用清晰的 `// TODO: ...` 或 `# TODO: ...` 注释标出待填位置，其余上下文与打印语句保持完整；
- `expected_output`：将挖空处正确补全后程序的完整标准输出，逐字符精确（含空格与换行）。

## 输出格式（严格遵守）
只输出一个合法 JSON 对象，不要任何代码块标记。不属于当前题型的字段按下方示例填空字符串 `""` 或空数组 `[]`：
{"exercises": [{"kind": "choice / fill / code", "kp_index": 1, "title": "精炼题目标题（15字内，无冒号）", "task": "题目描述（Markdown）", "language": "仅代码题填语言，其余填 \"\"", "skeleton_code": "仅代码题填框架代码，其余填 \"\"", "expected_output": "仅代码题填标准输出，其余填 \"\"", "options": ["仅单选题填4项，其余填 []"], "answer": "单选题填字母 / 填空题填数组 / 代码题填 \"\""}]}

JSON 字符串中的换行必须写成 `\n`，反斜杠（如 LaTeX 的 `\frac`、代码里的 `\n`）必须写成双反斜杠 `\\`，内部双引号写成 `\"`。
