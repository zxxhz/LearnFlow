## 出题要求
- 共出 [[TOTAL]] 道题，每个知识点至少 1 道，题目数量在知识点之间尽量平均。
- 每道题用 `kp_index` 标注属于第几个知识点（从 1 开始，对应上面「知识点 N」的编号）。
- 难度由浅入深，覆盖概念辨析和简单运用；不出纯记忆原文的题。
- 只出三种可自动判分的题型：`"kind": "choice"`（单选）、`"kind": "fill"`（填空）、`"kind": "code"`（代码补全）。
- 题型分配看课程类型：
  - 编程类课程：三种题型大约各占 1/3，代码题 1-2 道即可；
  - 非编程类课程（高数、线代、物理等数理课，或理论概念课）：**只出单选题和填空题，不出代码题**。数理课的填空题可以考计算结果，题干里的公式用 LaTeX。

### 单选题（kind = "choice"）
1. `options` 为 4 个选项文本的数组（不带「A.」前缀），长度和风格尽量接近；
2. `answer` 填正确选项字母（"A" / "B" / "C" / "D"），正确答案位置随机分布；
3. 干扰项来自对概念的典型误解，不放明显荒谬的选项。

### 填空题（kind = "fill"）
1. `task` 里用 ______ 标出空位，每题一个空，答案是一个短语或数值；
2. `answer` 填所有可接受答案的**数组**，同义说法、等价写法都列上（如 `["1/2", "0.5"]`）。

### 代码题（kind = "code"，仅编程类课程）
1. 语言固定为 [[LANGUAGE]]，`language` 字段填 `[[LANGUAGE]]`；
2. 单文件可独立运行，只用标准库；**禁止从标准输入读取**，不用随机数、时间、文件、网络，输出必须完全确定；
3. `skeleton_code` 只挖空 1-2 处关键代码，用 `// TODO：` 或 `# TODO：` 注释标出，其余部分完整可编译；
4. `expected_output` 为补全正确后程序的完整标准输出，逐字符精确（含空格和换行）。

## 输出格式（严格遵守）
只输出一个 JSON 对象，不要代码块标记。非本题型的字段留空字符串或空数组：
{"exercises": [{"kind": "choice / fill / code", "kp_index": 1, "title": "题目标题（15字内）", "task": "题目描述（Markdown）", "language": "仅代码题", "skeleton_code": "仅代码题", "expected_output": "仅代码题", "options": ["仅单选题"], "answer": "单选题填字母 / 填空题填数组"}]}

JSON 字符串中的换行写成 `\n`，反斜杠（如 LaTeX 的 `\frac`、代码里的 `\n`）写成 `\\`，双引号写成 `\"`。
