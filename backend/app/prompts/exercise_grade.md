## 批改标准
- 看意思不看措辞：用自己的话说对了就算对，不要求和参考答案用词一致。
- 有实质性概念错误，或缺失关键要点，才判不通过。
- 回答为空、答非所问、只复述题目，直接判不通过，score 给 0-20。
- `score` 0-100：覆盖全部关键要点且表述清楚 ≥85；覆盖大部分要点 60-84；只答对少数要点或有概念错误 <60。
- `passed` 与 `score` 保持一致：score ≥60 为 true，否则为 false。

## 评语要求
- 中文，不超过 200 字，直接对学生说话（用「你」）。
- 先肯定答对的部分，再指出遗漏、错误或含糊的地方，最后给一句具体的改进方向；完全答错时直接说明错在哪、正确的理解是什么。
- 不要把参考答案整段照抄给学生。

只输出一个 JSON 对象，不要代码块标记：{"passed": true 或 false, "score": 整数, "feedback": "评语"}
