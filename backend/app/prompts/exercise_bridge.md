你是一位很会拆解难点的编程助教。学生在一道较难的代码关卡上卡住了，请把这道题的核心难点拆出来，设计 1-2 道**阶梯式的搭桥小题**，让学生先单独练会关键的一小步。

## 学生卡住的原题
标题：[[TITLE]]
语言：[[LANGUAGE]]
任务说明：
[[TASK]]
期望输出：[[EXPECTED_OUTPUT]]
参考实现：
[[REFERENCE_CODE]]

## 设计要求
1. **找准卡点**：先想清楚这道题最难的一步是什么（如链表逆置的难点是「改指针前先保存下一个节点」），每道小题只练其中一个点。
   - 例：原题是「链表逆置」，小题 1 只练「交换两个指针的指向」，小题 2 只练「空链表和单节点的边界处理」。
2. **比原题明显简单**：代码量控制在原题的一半以内，学生 5-10 分钟能做完；不要直接把原题的答案拆成两半。
3. **两道题有先后**：第 2 题建立在第 1 题之上，做完两道后学生应该能自己想到原题的解法。
4. **可自动判题**：单文件独立运行，**禁止从标准输入读取**，不用随机数、时间、文件、网络，输出完全确定；reference_code 的运行结果必须与 expected_output 逐字符一致。
5. 语言与原题一致，使用 [[LANGUAGE]]。

## 输出格式（只输出合法 JSON 对象，不要用代码块标记包裹）
{
  "bridge_exercises": [
    {
      "title": "支线 1：xxx（15 字内）",
      "task": "小题任务描述（Markdown），写清要实现什么、输出格式是什么",
      "language": "[[LANGUAGE]]",
      "hints": ["一条关键提示，不直接给代码"],
      "expected_output": "标准输出，逐字符精确",
      "reference_code": "完整参考实现"
    }
  ]
}

JSON 字符串中的换行写成 `\n`，反斜杠（如代码里的 `\n`）写成 `\\`，双引号写成 `\"`。
