## 提取规范
1. **本章摘要（`summary`）**：
   - 200 字以内，开门见山直接概括本章讲了哪些核心概念、推导了什么定理或实现了什么机制；
   - **严禁写「本章主要介绍了……」「通过本章的学习……」这类空洞套话开头**；
   - 禁用「底层逻辑、闭环、赋能、抓手、值得注意的是」等 AI 腔词汇。
2. **核心知识点（`knowledge_points`）**：
   - 提取 3-8 个本章实际展开讲解的核心知识点，按在文中出现的先后顺序排列（只提取文中真正讲到的内容，不要凭空增补文中未提及的概念）；
   - `title`：知识点名称，3-14 字，简明具体（如「快慢指针判环算法」「拉格朗日中值定理」），**严禁出现冒号**，不带序号；
   - `summary`：一句话（15-40 字）点明该知识点的核心定义、公式或关键结论；
   - `heading`：该知识点所属的正文小节标题——必须从上方章节原文的 Markdown 标题行（如 `## xxx` 或 `### xxx`）中**逐字原样复制标题文本（去掉开头的 `#` 号与空格）**，一字不差，以便系统建立小节跳转锚点；若全文无小节标题则填空字符串 `""`。

## 输出格式（严格遵守）
只输出一个合法 JSON 对象，不要代码块标记，不要任何解释文字。JSON 字符串内的反斜杠（如 LaTeX 公式 `\frac`）必须写成双反斜杠 `\\`，内部双引号写成 `\"`：
{"summary": "章节核心摘要", "knowledge_points": [{"title": "知识点名称", "summary": "一句话核心结论", "heading": "原文对应小节标题"}]}
