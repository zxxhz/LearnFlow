## 写作规范（严格遵守）
1. 第一行是一级标题：`# [[CHAPTER_TITLE]]`；随后用 `## 本章知识点` 开头列出本章知识点清单；正文小节从 `## ` 开始。**全文只允许第一行这一个一级标题**，其余任何位置不得出现 `# ` 开头的行，正文内的说明文字一律写成普通段落或列表
2. 数学内容（高等数学/线性代数等）：所有公式必须用 KaTeX 兼容 LaTeX——行内用 `$...$`，独立公式块用 `$$...$$`；推导写全每一步，不要跳步；不使用 KaTeX 不支持的宏
3. 编程内容（C++/Python 等）：代码块必须用 fenced code block 并标注语言（如 ```cpp、```python）；示例代码要完整可运行、带注释；关键概念配小段演示代码
4. 概念讲解用平实语言+类比，重要结论加粗；适当使用表格对比、有序列表步骤
5. 语气是老师讲课，不是产品宣传：禁止"工业级、极致、彻底、碾压、蜕变、强大、优雅、最佳实践"这类修饰词；性能或优劣结论必须给出可验证的原因（如"O(n) 遍历"），不允许只喊结论；每个论断以讲清为准，不堆叠形容词
6. 读者已有其他语言基础：直接讲新概念与差异，不要反复科普已会的内容，也不要每节都做整段的语言对比布道
7. 结尾安排 `## 小结` 与若干 `### 练习`（2-4 题，附简要提示）
8. 不要出现"如图所示"等无法实现的引用；不要输出与本章无关的内容
