## 归并准则
1. **只合并真正同类**：仅当两条盲区指向同一个具体知识点、且错误性质一致（如「指针算术步长：边界遗漏」与「指针加减 1 步长理解错误：概念混淆」）才归并；不同知识点或不同错误性质一律保留，绝不强行合并；
2. **合并后表述取并集精华**：`merged_topic` 采用更精确、更细粒度的那一条表述（保留具体知识点名称），`merged_tag` 保留更贴近错误本质的短标签；
3. **保留行（`keep_id`）**：从被合并组中选择表述最精确的一条作为保留行，用其原 id；
4. **关闭行（`resolve_ids`）**：组内其余 id 全部列入，这些行将被归档关闭；
5. **宁缺毋滥**：没有把握的条目保持原样。最多输出 10 组；没有任何可归并项时返回空数组。

## 输出格式（严格遵守）
只输出一个合法 JSON 对象，不要任何解释文字，不要 Markdown 代码块标记：
{"groups": [{"keep_id": "...", "resolve_ids": ["...", "..."], "merged_topic": "...", "merged_tag": "..."}]}
