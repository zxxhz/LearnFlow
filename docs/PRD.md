## 1. 背景与目标

### 1.1 背景与问题

自学编程语言（如 C++）和高等数学等强逻辑课程时，自学者反复面临核心痛点：

- **资料不成体系**：网上的零散教程深度参差、顺序混乱，难以针对个人基础量身定制渐进路径。
- **疑问被搁置**：阅读中遇到不懂的函数、定理、推导，缺少即问即答且答案可沉淀的渠道；疑问散落在脑海或各种零散聊天窗口，无法回溯。
- **"假懂"无法暴露**：看完觉得自己懂了，实际动手写不出来——缺少从零编码输出、真实客观执行判定的机制。
- **普通 Chat 缺乏伴学感知**：传统 AI 对话只是被动回答，学习者在练习卡壳时往往直接得到现成答案，破坏了主动思考过程；且缺乏真实代码沙箱实测与工具链调用能力。

### 1.2 产品目标

打造一款**个人本地部署、隐私优先的 Agentic 伴学与练习系统**：

1. **体系化讲义生成**：用户输入学习目标，AI 生成结构化大纲，确认后逐章编撰体系化讲义，支持 LaTeX 公式与代码高亮。
2. **划线深度研讨**：阅读中可**划线**任意文字、公式或代码，弹出卡片与 AI 进行沉浸式**多轮对话**，标注与对话记录原位永久持久化。
3. **链式闯关练习**：各知识点生成由浅入深的关卡链，每关提供任务描述、目标输出与渐进提示（Hints），学习者**无骨架从零手写代码**，本地沙箱真实运行判通才解锁下一关；支持基于 SymPy 的**代数等价客观判题**。
4. **启发式伴学 Agent（Tutor）**：闯关失败时呼叫助教，基于报错与代码提供苏格拉底式启发诊断；具备**动态自主工具链（Tool Calling）**，可自主运行沙箱验证、绘制函数图像与透视关卡，建档学习者认知画像与易错模式。
5. **独立题库刷题**：内置独立题库引擎，支持 Excel 批量秒级导入单选/多选/判断题，支持 10/20/50 题极速随机组卷与卡片式作答。
6. **双轨错题清零**：练习与题库做错的题目自动沉淀至专属**错题池**，集中专练重刷，通过后自动出池。
7. **全端互联与纯本地存储**：原生提供局域网访问开关（带访问令牌保护），全端支持 PWA 独立窗口运行（桌面/平板/手机）；所有数据落于本地 SQLite 与 Markdown。

### 1.3 成功标准

- 从输入"我想学 C++ 基础"到读上第一章文档，全程流畅高效（含大纲协同确认）。
- 划线提问链路（选中 ➔ 弹卡 ➔ 提问 ➔ SSE 流式输出）平滑，标注与对话历史 100% 可回溯。
- 启发式助教诊断不直接剧透答案，能够精准指出思维漏洞并结合沙箱工具实测辅导。
- 知识点关卡链严格遵循前置关卡通关才解锁，从零手写代码保证检验客观有效。
- 题库支持百题级 Excel 秒级解析入库并平滑刷题。
- 学 ➔ 问 ➔ 练 ➔ 伴 ➔ 刷 全链路数据彻底打通，数据复制即完成备份。

## 2. 用户画像与使用场景

**用户**：自学编程与数理课程的深度学习者、竞赛备考者（个人使用，无多用户冗余）。

**设备**：Windows 桌面端为主；支持局域网内平板（iPad 等）与手机浏览器访问（PWA 全屏独立应用）。

**典型场景**：

1. **晚间体系精读与闯关**：打开桌面端 ➔ 继续阅读 C++ 讲义 ➔ 划线研讨指针与内存布局（多轮对话记录在文档原位）➔ 开启该知识点闯关练习 ➔ 从零手写代码完成前两关，第三关编译报错 ➔ 呼叫助教启发诊断，助教指出边界条件偏差 ➔ 修改代码通过第三关 ➔ 解锁参考实现。
2. **碎片时间题库速刷**：平板打开已添加到主屏幕的 LearnFlow PWA ➔ 选择题库刷题 ➔ 抽取 20 题随机组卷 ➔ 卡片式速刷单选/多选/判断 ➔ 提交后即刻出分 ➔ 错题自动汇入错题本 ➔ 针对错题专项重刷直至全部通过。
3. **高等数学图形辅助研讨**：学习微积分文档 ➔ 文档内 ` ```plot ` 代码块一键绘制函数曲线 ➔ 闯关代数关卡输入数学化简表达式 ➔ 系统基于 SymPy 代数等价引擎瞬间客观评判。

## 3. 核心学习闭环

系统功能紧密围绕“学、问、练、伴、刷”五位一体闭环运转：

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   学 ──── 输入目标 → 大纲协同确认 → 逐章流式生成讲义 → 沉浸阅读器  │
│   │                                                             │
│   │ 遇到疑问：划线 → 弹出研讨卡片 → 多轮深度提问（AI 答疑）      │
│   ↓   标注与问答历史原位持久化，形成个人“精读疑问档案”          │
│                                                                 │
│   练 ──── 链式闯关：渐进提示 + 目标输出常显，从零手写代码/表达式 │
│   │        沙箱/代数运行判定 → 通过解锁下一关 → 通关见参考实现  │
│   ↓        暴露的薄弱知识点直接反映于掌握度仪表盘               │
│                                                                 │
│   伴 ──── 遇阻召唤启发式助教：苏格拉底式诊断思维漏洞与盲区      │
│   │        助教自主调用 Tool Calling 工具链（沙箱/绘图/透视）    │
│   ↓        持久化更新学习者认知画像与易错模式模型               │
│                                                                 │
│   刷 ──── 练习错题自动进错题本，集中攻坚直至重刷通过出池        │
│            独立题库模块：Excel 批量导入 → 随机组卷 → 错题专项专练 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**数据互通机制**：
- 讲义生成时自动提取结构化知识点（`knowledge_points`），作为练习关卡链与掌握度评估的锚点。
- 闯关练习关联 `knowledge_point_id` 与 `document_id`，练习作答失败与薄弱点可直接回链讲义位置。
- 错题池采用追加式流水驱动，以每道题最新一次作答状态动态派生，重刷通过即时出池。

## 5. 功能需求

### 5.1 课程与讲义生成

**FR-1.1 创建课程**
- 入口：首页「新建课程」。
- 输入：学习主题（如 "C++ 核心编程"、"高等数学微积分"）、背景水平（零基础/有其他语言基础/进阶）、期望深度与章节偏好。
- 流程：提交后由生成场景模型生成课程大纲 JSON（章标题 + 每章要点 bullet + 预估难度），进入大纲协同确认页。

**FR-1.2 大纲协同确认（人机协作质量闸门）**
- 用户可在确认页进行：编辑章标题、增删章节、拖拽排序、修改每章要点、整体追加调整指令重新生成。
- 确认后大纲锁定为课程权威属性，后续逐章流水线严格以此为准。

**FR-1.3 逐章生成流水线**
- 确认大纲后启动异步生成任务：按章节顺序生成，每章调用一次生成模型（上下文携带全局大纲 + 前置章节摘要，避免全文冗余保证控流）。
- 每章生成产物：写入 Markdown 文件 ➔ 解析建立 Section 稳定块索引 ➔ 抽取结构化知识点 ➔ SSE 实时推送进度。
- **断点续生成**：任务状态按章持久化（pending / generating / done / failed），异常中断后重开可继续未完章节，失败章支持单章重试。

**FR-1.4 讲义内容规范**
- 代码块强制使用带有语言标识的 fenced code block（```cpp、```python），示例代码可编译可运行。
- 数学公式强制兼容 KaTeX 语法（行内 `$...$`，独立块 `$$...$$`）。
- 严格结构限制：全文不超过篇幅预算（默认 2000-4000 字），小节不超过 5 节，每节不超过 800 字与 2 个代码块；严禁浮夸修饰，结论须给出可验证原理。
- 生成时单次调用同时输出正文 + `<LEARNFLOW_META>` 分隔符 + JSON 元数据（章节摘要与知识点清单），免去二次调用开销。

**FR-1.5 自有 Markdown 笔记导入**
- 支持上传本地 `.md` 文件导入课程：机械切章规则（≥2 个 H1 按 H1 切，否则 ≥2 个 H2 按 H2 切，整文件兜底一章），章内次级标题提取为大纲要点。
- 原文精确切片保留，完整源文件只读归档至 `courses/{id}/originals/`，不擅自改写用户笔记。
- 课程与题库均支持在列表或详情页随时行内重命名。

### 5.2 阅读器与检索系统

**FR-2.1 文档渲染引擎**
- 基于自研块渲染器：后端 `markdown-it-py` 与前端 `markdown-it` 同源解析，保障顶层块结构与行号完全对齐。
- 集成 KaTeX 公式解析与 Shiki 双主题代码高亮；每个块级元素携带唯一稳定 `section_id`。
- 目录导航：左侧树状目录，当前阅读位置实时高亮，点击平滑滚动；记录章节阅读滚动进度。

**FR-2.2 全局搜索与问整门课**
- **FTS5 全文检索**：利用 SQLite FTS5 全文索引实现跨课程全文检索，毫秒级返回命中片段并高亮匹配词，点击一键跳转原文定位。
- **问整门课**：在课程详情页可向全课程直接提问，后端自动组装全局大纲、章节摘要及检索命中文档片段拼装上下文，通过 SSE 流式输出全书级答疑。

### 5.3 划线提问卡片（核心交互）

**FR-3.1 划线交互与双重锚定**
- 鼠标选中文本（触屏长按选择）后即刻浮现轻量浮动条：提供「提问」、「高亮」及 4 种高亮配色。
- 划线最小粒度为块内文本；创建时记录五元组：`(section_id, exact, prefix, suffix, offset_hint)`。

**FR-3.2 沉浸式研讨面板**
- 右侧滑出独立研讨抽屉（宽度约 420px，不遮挡主阅读区），展现划线原文引用、历史对话列表与底部输入框。
- 对话上下文自动注入划线原文、所在小节内容及章节摘要，保障 AI 答疑严格基于教材原文。
- 标注、修改笔记、换色与多轮问答均实时落库，重开讲义原位高亮与对话完整复现。
- 文档更新后若块内容变动，先走 diff-match-patch 模糊锚定，完全脱锚时进入 `orphan` 状态，支持在标注抽屉中一键手动「重新挂载」。

### 5.4 启发式伴学 Agent（Tutor）

> 系统彻底摆脱单向问答聊天，形成具备感知、诊断与自主工具调用的伴学智能体。

**FR-4.1 伴学感知与启发式诊断**
- 在闯关关卡作答未通过或执行报错时，卡片自动浮现「💡 呼叫助教启发诊断」入口与追问框。
- 助教接入 `/api/tutor/diagnose` SSE 流式通道；系统自动组装任务背景、标准输入输出约束、用户代码实现、编译器/沙箱报错信息及学习者认知档案。
- **苏格拉底式启发原则**：助教绝不直接输出最终答案或标准代码，而是以引导性提问剖析思维误区与边界遗漏，启发学习者自主修正。
- 提供「💡 启发引导」与「📖 详细直答」双模态自由切换。

**FR-4.2 动态自主工具链（Tool Calling 闭环）**
- 助教具备工具自主调用循环（Agent Loop）：
  - `run_sandbox_code`：自主向本地沙箱提交精简测试用例，实测学习者的代码猜想；
  - `render_math_plot`：动态调用 SymPy 生成函数图像帮助学习者建立几何直觉；
  - `inspect_exercise`：透视当前关卡的测试用例规范与输入输出契约。
- 前端实时透传 `tool_call` 事件并在 UI 呈现动态执行动效；若用户所配置的模型不支持 Function Calling，系统自动平滑回退纯文本推理，保障服务 100% 稳定。

**FR-4.3 学习者认知画像持久化**
- 数据库持久化建档 `learner_profiles`（先验知识背景、偏好引导模式）与 `learner_misconceptions`（易错概念模式、错误证据、修复状态）。
- 助教在伴学过程中持续沉淀学习者的思维盲区，并在后续出题与辅导中提供千人千面的针对性指引。

### 5.5 独立题库刷题模块

**FR-5.1 题库管理与 Excel 导入**
- 独立于课程体系的刷题引擎，支持通过 Excel 文件（`.xls` / `.xlsx`）批量秒级导入题库。
- 自动识别并解析题干、选项 A-H、正确答案、难度与试题解析，支持**单选题、多选题、判断题**三种主流客观题型。
- 题库列表以卡片式展示，呈现题量与题型分布，支持随时重命名与独立管理。

**FR-5.2 卡片式高效刷题与组卷**
- 支持按题库自由发起 10 题、20 题或 50 题一轮的随机组卷快刷模式。
- 卡片式高效排版，键盘/触屏快捷点击选项，支持多选组合提交与判断题快速裁定。
- 提交后即刻客观判分，展示标准答案与详尽文字解析。

**FR-5.3 动态错题池机制**
- 作答记录追加写入 `bank_attempts` 流水；系统依据每道试题的**最新一次作答状态**动态派生错题池。
- 提供「错题重刷」专项入口，错题重刷通过后即刻自动移出活跃错题池。

### 5.6 学习仪表盘

- **掌握度评估**：以闯关练习的真实通过率作为知识点掌握度评分核心指标（0-100）。
- **薄弱知识点榜单**：展示掌握度最低的 Top 知识点，支持一键跳转到讲义对应章节或练习。
- **学习行为热力图**：按天统计学习动态分布（阅读、练习作答、对话研讨）。
- **阅读时长与 Token 消耗**：统计累计阅读时长看板；按生成（generation）与对话（chat）场景统计近 30 天 Token 消耗流水。

### 5.7 系统设置与数据管理

- **LLM 供应商预设**：支持智谱 GLM、DeepSeek、OpenAI、Moonshot、Ollama 本地模型与 Gemini 兼容端点；提供「测试连接」即时检测连通性与延迟。
- **场景化模型分流**：支持生成讲义（generation）与对话伴学（chat）配置不同模型，高级模型配置支持折叠收拢。
- **原生局域网开关**：原生提供平滑 Switch 开关（默认监听 `0.0.0.0`），直观呈现局域网访问地址与访问令牌（Token），支持随时一键重新生成令牌。
- **纯本地数据备份**：明确展示本地数据目录路径；设置页支持一键打包导出全部数据（SQLite + 课程讲义）为 zip 备份，支持历史备份一键恢复与管理。

### 5.8 代码运行沙箱与便携工具链

- **安全执行沙箱**：讲义与练习代码块内置「▶ 运行」按钮：
  - Python：基于 `-I -B -X utf8` 隔离模式运行，禁止外部包干扰，仅限安全标准库；
  - C++：自动调用本地 `g++` / `clang++`，以 `-std=c++17 -O0` 编译并执行；
  - 沙箱限制：单次执行硬限 10 秒（超时直接终结进程树）、内存限额 256MB（Windows Job Object）、关闭标准输入、每次执行分配一次性隔离临时目录，执行结果随文档全量持久化。
- **一键便携式环境安装**：设置页「代码运行环境」自动探测系统/内置环境；未安装 C++ 编译器时可一键后台静默下载安装 niXman MinGW-w64 (GCC 14.2.0) 便携包；支持华为云等镜像智能择优、断点续传与 SHA-256 哈希校验，解压至软件目录，不修改系统环境变量与注册表。

### 5.9 函数图像绘图

- 讲义支持 ` ```plot ` 代码块，每行输入一个数学函数（如 `sin(x)/x`、`f(x)=x**2 - 4`）。
- 点击「📐 绘图」调用 SymPy 与 Matplotlib 实时解析生成高清函数图像，支持多函数自动叠加对比与奇点自动断线。

### 5.10 链式闯关练习系统

- **链式关卡解锁**：按知识点自动生成由浅入深的关卡链（默认 3 关），前一关通过方可解锁下一关（通关状态永久记录），未解锁提交直接被服务端拒绝（403）。
- **零骨架从零手写**：题面明确要求程序输出目标并常显，**不提供预置代码骨架**，倒逼学习者从零动手；配套 2-3 条渐进式提示（Hints，默认只展示第 1 条，攻坚卡壳时按需逐条展开）；通关后展示参考实现。
- **SymPy 代数等价判题引擎**：新增 `math` 练习题型，利用符号代数化简判定 `simplify(u - e) == 0`，支持乘法交换律、同类项合并、指数展开等客观数学等价性验证。
- **错题自动进池与随堂小测**：做错题目自动纳入错题本，重刷通过后自动移出；支持跨知识点随机抽题组合「随堂小测」测试出分；存量选择/填空/概念题作为支线保留。

### 5.11 局域网访问与 PWA 跨端支持

- **局域网安全准入**：后端默认监听 `0.0.0.0:8420`，非本机来源的所有 HTTP / SSE 请求必须携带访问令牌（`?token=...` 或 `X-Access-Token` 头），静态前端资产白名单放行，初次访问自动写入安全 Cookie。
- **全端 PWA 支持**：配置 Web App Manifest、全尺寸自适应高清图标与独立 Service Worker，静态资源缓存优先、API 直通网络、离线平滑回退；iPad Safari 或安卓 Chrome/Edge 可直接「添加到主屏幕」化身独立全屏 App 体验。

## 9. 划线标注锚定方案

### 9.1 双重锚定数据结构
创建标注时生成稳健五元组：
- `section_id`：所属块稳定 ID（结构定位第一重锚）；
- `exact`：划线纯文本（内容验证第二重锚）；
- `prefix` / `suffix`：划线前后各约 32 字符环境上下文（模糊计算依据）；
- `offset_hint`：块内字符位置提示（加速定位参考）。

### 9.2 渲染时定位机制
1. 根据 `section_id` 命中目标块级 DOM 元素；
2. 依据 `offset_hint` 尝试精确比对 `exact` 原文；
3. 未精确命中时，在块内执行 diff-match-patch 上下文模糊匹配（阈值 0.8）；
4. 匹配失败时标记为 `orphan` 状态，在抽屉中保留记录并提供「重新挂载」入口。

## 10. 核心算法与业务流水线

### 10.1 讲义生成流水线
- 提示词工程严格约束输出结构；单次请求利用 `<LEARNFLOW_META>` 分隔符拆分正文 Markdown 与知识点 JSON。
- 采用局部摘要传递机制，前置章节仅传递 300 字摘要，严格控制上下文 Token 膨胀。

### 10.2 启发式助教 Agent Loop
1. **感知与构建**：提取练习题干、预期输出、学习者代码、编译器报错与学习者易错历史；
2. **多轮决策**：LLM 判定是否需要调用工具。若需要，产出 Tool Call 指令并发往沙箱/绘图模块执行，执行结果回填为 `tool` 角色消息再次由模型决策；
3. **输出指引**：整合诊断结论，通过 SSE 输出苏格拉底式启发引导。

### 10.3 双引擎客观判题机制
- **代码沙箱判定**：stdout 进行去空行、去首尾空白规范化后比对，完全一致即判通过；
- **SymPy 代数等价判定**：针对数学关卡，将用户答案 $u$ 与标准答案 $e$ 转换为符号表达式，执行 `simplify(u - e) == 0` 进行数学等价裁决，支持乘法交换律、同类项合并及展开变换。

### 10.4 动态错题池派生算法
错题本不维护僵化状态机，而是基于作答历史使用 SQL 窗口函数：
```sql
SELECT * FROM (
    SELECT *, ROW_NUMBER() OVER(PARTITION BY exercise_id ORDER BY created_at DESC) as rn
    FROM exercise_attempts
) WHERE rn = 1 AND passed = 0;
```
最新一次作答未通过即入池，重刷通过后最新记录变为 passed=1，自动退出错题池。

## 13. 风险与应对

| 风险点 | 潜在影响 | 应对措施 |
| --- | --- | --- |
| 上游大模型输出不合规 | 导致判题或大纲解析崩溃 | 引入 Pydantic 结构化强校验与最大 2 次重试兜底；消息层规整兼容 Gemini 400 等端点异常。 |
| 本地沙箱恶意代码或无限循环 | 占用系统资源或死锁 | Windows Job Object 硬限 256MB 内存；10 秒强制限时杀灭进程树；严格禁止任意包安装与网络访问。 |
| 文档重新生成后标注丢失 | 用户研讨历史数据受损 | 实施块 ID 稳定对齐 + 前后文模糊计算 + orphan 重新挂载流程，保证数据永不物理丢失。 |
| 局域网服务暴露安全隐患 | 未授权设备访问代码沙箱 | 默认绑定局域网时强制启用高强度访问令牌鉴权；设置页支持一键随时吊销旧令牌。 |

## 14. 非目标（Non-goals）

为保证系统专注、极简与高质量，以下内容明确不纳入范围：
1. **不做多用户 SaaS 与云端存储**：坚持纯本地运行、隐私第一，数据完全归用户所有；
2. **不做花哨的外围游戏化**：坚决排除脱离自学主线的番茄钟、社交排行榜、虚拟徽章等繁杂功能；
3. **不做公开课程市场**：课程包导出与导入仅服务于个人备份与多设备迁移；
4. **不做在线通用 IDE**：沙箱定位为教材示例与关卡检验，不提供任意第三方依赖安装与长任务调度；
5. **不重回记忆卡与假懂对话**：坚决放弃填鸭式的间隔重复卡片（SM-2）与形式化费曼对话，全面坚持“从零动手编码闯关 + 启发式诊断”。

## 16. 架构决策与实现演进记录

1. **阅读器渲染架构优化**：放弃庞大的富文本编辑器，采用自研轻量块渲染器——后端 `markdown-it-py` 与前端 `markdown-it` 同源解析，结合 KaTeX 与 Shiki，保证块结构与行号绝对对齐。
2. **严格单调时间戳保障**：Windows 系统下 `time.time()` 存在约 15.6ms 粒度限制，导致同一时刻写入的时间戳出现平局排序混乱。系统已全面升级 `utcnow_iso()` 保证进程内时间戳严格单调递增，彻底消除错题本排序随机性。
3. **安全沙箱环境落地**：Windows 下通过 Job Object 施加内存 256MB 与时长 10 秒硬限制；Python 采用 `-I -B -X utf8` 隔离模式；C++ 缺失时提供清晰指引与一键便携安装。
4. **便携式编译器后台安装**：支持后台一键下载解压 niXman MinGW-w64 (GCC 14.2.0) 与 Python embeddable 环境，智能择优国内镜像、支持断点续传与 SHA-256 校验，解压至应用目录，不污染系统环境。
5. **练习系统全面闯关化**：关卡改造为链式解锁；题目必须常显预期输出并提供 2-3 条渐进 Hints；彻底取消预填骨架代码，逼迫从零手写；通关后呈现标准参考实现。
6. **移除费曼模式与 SM-2 复习模块（v0.4.0）**：彻底删除历史 feynman 与 review 库表与路由；掌握度收敛为闯关练习通过率单一权威信号；模型场景槽位精准收敛为 `generation`（生成）与 `chat`（对话伴学）。
7. **独立题库刷题模块上线（v0.3.0）**：独立于课程系统建立题库与刷题表结构，支持 Excel 批量秒级解析，实现 10/20/50 题极速随机组卷与卡片式作答。
8. **启发式伴学 Agent 体系落地**：新增伴学诊断路由与自主 Tool Calling 运行机制；建立 `learner_profiles` 与 `learner_misconceptions` 认知模型；引入 SymPy 代数等价客观判题。
9. **局域网访问与 PWA 全端支持**：设置页提供原生局域网 Switch 开关与访问令牌管理；配置 Web App Manifest 与 Service Worker 缓存，移动端与平板支持无缝添加到主屏幕。
10. **Tauri 桌面端与自动更新守护**：集成 `UpdateDialog` 居中更新弹窗，结合 minisign 验签一键静默升级；NSIS 安装器配置进程守护钩子，自动清理后台残留孤儿进程，杜绝文件锁定报错。
11. **右侧全景面板统一动效与正文自适应避让（v0.4.21）**：将闯关练习抽屉、标注抽屉、知识点抽屉以及划线提问卡片统一纳入平感动效体系；展开时面板从右滑入，桌面端正文向左平移避让（`md:mr-[420px]`，300ms ease-out），避免遮挡文字与公式；关闭时平滑复原。划线提问 0ms 乐观渲染气泡并升级底层流式链路为原生 `ReadableStream` 毫秒级打字机输出。
12. **目录独立固定与平滑折叠动效（v0.4.19 / Ctrl+B）**：重构双栏结构，左侧目录树固定在视口左侧独立滚动，不随右侧正文滚动而位移；支持快捷键 <kbd>Ctrl</kbd> + <kbd>B</kbd>（Mac: <kbd>Cmd</kbd> + <kbd>B</kbd>）平滑折叠展开并记住用户偏好。
13. **检查更新自动无缝回退国内镜像（v0.4.20）**：在 GitHub 官方源（`api.github.com`）连接超时或不可达时，自动无缝切换到备用国内镜像加速通道（`ghproxy / fastgit`），保障国内网络升级可靠性。
14. **独立题库 AI 深度流式解答与题库提示词自定义（v0.4.22）**：`question_banks` 表新增 `ai_prompt` 字段，支持题库自由定制专属系统提示词并提供启发式金牌名师黄金提示词兜底；提供「✨ AI 润色提示词」一键结构化专家优化并原地替换文本；作答错误即刻提供「🤖 获取 AI 深度解析」，原生 SSE 打字机流式输出并渲染 KaTeX 公式。
15. **错题选项渲染修复与 AI 解析跨状态保留持久化（v0.4.23）**：小结列表统一采用 `visibleOptions` 重构选项渲染（单选/多选/判断全覆盖）；`bank_questions.ai_explanation` 字段持久化，作答时生成的解析在查看小结与未来刷题中永久保留、0ms 秒开无重复请求，支持重新生成。
