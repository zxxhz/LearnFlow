输入想学的科目（如 C++ 进阶、离散数学、网络安全、现代密码学），AI 生成大纲并逐章撰写讲义。也可以导入自己的 Markdown 笔记、PDF 教材或题库表格。阅读时可随时划线提问或记录个人手写随笔，做题卡关时有带工具调用（代码沙箱实测、函数绘图）的伴学助教启发提示；另外内置了首页「今天」行动中枢、独立思维导图网状画布、多题型刷题、代码手写闯关、因材施教的学习者认知画像以及**自建云端中转与纯 Web 学习（Docker 一键部署）**。

所有数据完全存放在本地，支持接入各大兼容 OpenAI 协议的模型（DeepSeek、智谱、Moonshot、OpenAI、Gemini 等）或本地部署的 Ollama。

## 核心功能

### 1. 首页「今天」学习行动中枢
- **秒回上次研读**：打开应用第一眼清晰呈现上次学习的课程与章节，一键直达对应阅读进度与锚点。
- **暂存硬骨头攻坚直通车**：聚合全课程标记为“硬骨头”的卡壳关卡，随时点击发起回击攻坚。
- **题库错题待清零聚合**：动态汇总全题库待清零错题与存疑题目总数，一键跳转专项刷题。
- **学情与专注时长**：直观展示当日学习专注净投入时长（分钟）与当前活跃认知盲区标签。

### 2. 课程生成、讲义阅读与单段手术式纠偏
- **大纲生成与单章控制**：输入目标生成大纲树，支持手动调整章节顺序与标题；逐章异步流式生成讲义，支持中途断点续传与单章独立重生成。
- **多类型自有材料导入（Markdown / PDF）**：
  - **Markdown 笔记**：直接导入外部笔记，自动根据标题层级拆解章节，原文完整保留不擅自改写；
  - **PDF 格式讲义**：基于轻量引擎提取，有文字层的 PDF 秒级直取全文（0 消耗零 Token），扫描版/图片型 PDF 自动逐页栅格化走多模态转写。
- **自主精读与章末 AI 视野自测**：默认关闭被动自动划线，倡导在精读中自主圈划核心要害；章末新增「抓重点能力自测：与 AI 视野对照」，统计重合与遗漏要点并支持一键采纳。
- **单段落「质疑有误」与手术式重写**：鼠标悬停任意段落或代码块浮现「🚩 质疑/重写」；支持向 AI 提出质疑（公式存疑、结论相反、代码有 Bug、求通俗化改写），AI 客观审校后仅针对单段落进行局部替换，不破坏整章与已有划线；替换后自动检测下游练习并提示联动更新。
- **章首耗时预估与章末结构复盘卡片**：章首标明预计阅读时间与关卡耗时；通关后在章末滑出仪式感复盘达成卡片，呈现本章击穿核心概念清单、攻坚印记数据与下一章先导预告。
- **ADHD 辅助阅读模式**：
  - 模式 A：12 种柔和马卡龙护眼色在正文段落、列表、引用块间循环交替，降低长文视觉疲劳；
  - 模式 B：鼠标悬停聚焦段落高亮并带微位移反馈。
- **独立字号调节与侧栏折叠**：课程与刷题支持独立 13px–24px 步进微调，公式与排版等比缩放；支持快捷键 <kbd>Ctrl</kbd> + <kbd>B</kbd>（Mac 下 <kbd>Cmd</kbd> + <kbd>B</kbd>）平滑收起左侧目录树。

### 3. 个人独立随笔批注与全课笔记汇编导出
- **划线动作双分流**：划选文字支持「💡 问助教」与「📝 记批注」；手写个人随笔想法零延迟即时落库，**不发起 AI 对话、0 Token 消耗**。
- **全书笔记汇编一键导出**：课程详情页与阅读器标注抽屉新增「📝 导出笔记汇编 (.md)」，将全书大纲结构、各章核心摘要、个人划线随笔原文与助教问答研讨回顾排版整合导出，可直接导入 Notion、Obsidian 复习。

### 4. 学科自适应闯关、防作弊与卡关救济
- **学科自适应关卡生成**：
  - **编程类课程**：全代码手写闯关链，前一关通过方可解锁下一关；
  - **数理类课程**：数学计算关（基于 SymPy 代数等价性自动判题，自动识别乘法交换律、幂次展开与化简表达式）与公式填空关；
  - **理论概念类课程**：递进式概念自测关（辨析单选、易混淆多选、填空题与客观场景短答题），杜绝非编程学科强套代码题。
- **防作弊硬编码直出拦截**：代码关若直接通过 `print(...)` 写死输出目标字符串，判定器自动拦截并友好提醒编写运算逻辑。
- **做题常驻「🤔 存疑 / 不确定」标记**：作答界面常驻存疑复选框；自学者即使凭运气蒙对，该题亦强制留存在待巩固错题池中，消除自我欺骗。
- **卡关搭桥支线小题**：遇到综合难题连续卡壳时，可一键呼叫助教「🧱 拆解做两道支线小题」，降低认知负荷单练微小步骤，做完平滑回归主线。
- **「🦴 标记为硬骨头先跳过」**：遇到瓶颈允许先标记硬骨头跳过，放行后续章节阅读，该题在首页行动中枢长期置顶攻坚。

### 5. 伴学 Agent 与启发式助教
- **双模态引导**：做题受阻时可呼叫助教，支持「💡 启发引导」（苏格拉底式反问、指出思路偏差、不直接给答案）与「📖 直答解析」两种模式自由切换。
- **Tool Calling 动态工具链**：助教集成自主工具调用闭环，可自主调用后端沙箱执行代码验证结果（`run_sandbox_code`）、动态绘制函数图像辅助几何理解（`render_math_plot`）或透视当前关卡状态（`inspect_exercise`），前端实时透传工具执行状态。

### 6. 题库刷题与剪贴板一键智能切题
- **剪贴板杂乱文本一键切题**：题库页新增「📋 粘贴文本切题」；支持直接粘贴从讲义、网页、课件或微信群复制的散乱试题纯文本，AI 自动切分题干、选项、答案与解析，提供高保真表格预览修改后秒级入库。
- **表格题库批量导入**：支持导入 `.xlsx` / `.xls` 格式的题库表格（单选、多选、判断等题型），题干与选项完整支持 Markdown 与 KaTeX 数学公式。
- **做新题与模考模式**：
  - 做新题模式：只抽从未作答过的题目，攻坚刷穿全库，做一题少一题，看板实时统计未做新题数；
  - 做题模式：全库随机抽题模拟自测，同套题内容严格指纹去重。
- **错题 AI 流式深度解答**：答错时一键唤起 AI 深度解析，包含错因诊断、核心考点、逐项辨析与举一反三；解析结果自动落库持久化，0ms 秒开查看，无需重复消耗 Token。
- **题库级专属提示词**：每个题库可单独配置答疑与命题专属 Prompt，支持一键点击「AI 润色提示词」原地优化。

### 7. 思维导图与跨分支网状知识图谱
- **自研原生渲染画布**：基于 React + SVG 贝塞尔曲线开发的层级树渲染引擎，无需重型第三方依赖；支持鼠标滚轮自由缩放（0.3x~2.5x）、画布平移拖拽、全屏居中与分支节点折叠/展开。
- **思维导图由“树”到“网”（跨分支横向语义关系网络）**：支持在任意两节点间拉出带箭头的横向虚线关系连线（如“底层基于”“容易混淆”“协同实现”）；点击节点同步微光高亮整个横向概念网络，节点详情抽屉聚合展示关联概念并支持一键跳转。
- **AI 画像生成与双向导入导出**：支持根据用户学习背景一键生成导图；支持 Markdown 大纲或 JSON 格式的双向导入与导出。
- **Agent 自然语言交互式控图**：侧边悬浮面板支持自然语言指令交互（如“在 XX 节点下拆解 3 个关键子项”、“删掉废弃分支”），由 Agent 通过结构化工具实时操作内存树并同步画布。
- **节点详情抽屉与专属知识问答**：点击任意节点平滑滑出详情抽屉，支持调用 AI 一键深度剖析底层原理、直观类比与易混淆盲区，支持围绕当前节点的上下文多轮追问。

### 8. 学习者画像与因材施教（分学科隔离）
- **认知画像持久化**：建立 `LearnerProfile`（技术背景、先验知识栈、引导偏好）与 `LearnerMisconception`（易错模式、高频概念盲区、掌握状态、证据链回溯）。
- **学科隔离防串味**：盲区按学科域（💻 编程 / ∑ 数理 / 📖 理论 / 🌐 通用）严格隔离注入，学高数不再被编程盲区干扰。
- **证据链溯源与自动闭环**：盲区卡片标明出处题干并支持直达；该错题独立做对且未标记存疑后，盲区自动标记已击破；活跃盲区超量自动后台归并。
- **全链路 Prompt 注入与后台轻模型**：大纲设计、章节教材撰写、划线问答、伴学助教诊断及错题解析全面注入画像；支持配置独立的「后台轻模型」场景槽位，省钱不拖慢主对话。

### 9. 代码与函数绘图沙箱
- **力扣式代码块编辑与执行**：讲义内的 ` ```python ` 与 ` ```cpp ` 代码块右上角带有运行按钮，支持在正文中直接修改代码并运行测试，支持重开回显历史结果与一键重置回初始代码。
- **执行安全隔离**：单次运行限时 10 秒（超时自动终止进程树）、内存上限 256MB（Windows Job Object 红线约束）、stdin 关闭、一次性临时工作目录；Python 使用随包内置隔离环境，C++ 依赖本机 g++/clang++。
- **高数函数图像绘制**：` ```plot ` 代码块一键解析函数表达式并渲染高清矢量 SVG 图像，支持多函数同图对比与奇点自动断线（如 `sin(x)/x`）。

### 10. 出题沙箱自验与函数图像 AI 自修
- **出题落库前沙箱实测自验**：代码题生成后，先在本地沙箱静默执行参考代码并比对输出；输出不符由 AI 自动带报错修正一次；编译运行均失败直接弃用，绝不让坏题卡死学习者。生成关卡带有 `🧪 已实测` / `🧪 输出已校准` 勋章。
- **函数绘图块一键 AI 自修**：当讲义或错题解析中的数学函数图像绘制异常时，可点击「🤖 AI 修正」，AI 自动根据报错就地修正函数表达式并重新绘制。

### 11. 自建云端中转、反向隧道与纯 Web 独立学习
- **零公网 IP 反向穿透隧道（WebSocket Tunnel）**：本地电脑无需公网 IP 或配置端口映射，开机后自动与云端建立 `/ws/relay` 长连接反向隧道。
- **三种 AI 算力执行模式**：
  - 🔄 **智能自动模式 (`auto`，推荐)**：本地电脑在线优先调用本地算力与本地模型；电脑关机或离线时，**自动平滑降级由 VPS 云端大模型直出接管**，学习体验永不中断；
  - ☁️ **云端服务端模式 (`cloud`)**：强制由服务端大模型生成，外出手机、平板学习无需电脑开机；
  - 💻 **本地节点模式 (`local`)**：强制通过隧道穿透至本地电脑运行，调用本地显卡算力与代码沙箱，保护代码数据隐私。
- **云端数据持久化与双向合并同步**：课程、Markdown 讲义正文、题库题目、做题记录与思维导图一键同步至云端 SQLite；在外手机刷题做出的新记录，回家打开桌面端秒级双向合并。
- **手机/平板纯 Web 独立访问**：外出时直接通过浏览器访问云端 VPS 地址，享受和桌面端一致的完整学习与做题体验。

## 安装与运行

### 方式一：下载桌面安装包（推荐，开箱即用）
从 [Releases](https://github.com/zxxhz/LearnFlow/releases) 下载最新 `LearnFlow_x.x.x_x64-setup.exe` 安装运行。
- 安装包已内置完整运行环境，**电脑无需安装 Python 或 Node.js**；
- 运行 C++ 代码块需要编译器：本机已有 g++/clang++ 会直接使用；若没有，可在设置页「代码运行环境」一键下载便携版 MinGW-w64。

### 方式二：自建云端中转与 Docker 一键部署（支持手机平板纯 Web 学习）
通过 GitHub Packages 官方预编译镜像，在 VPS 上一秒启动包含**完整前端 Web SPA 界面 + FastAPI 中转后端**的一体化容器：

#### 1. 创建配置文件 `docker-compose.yml`
```yaml
version: "3.8"

services:
  learnflow-relay:
    image: ghcr.io/zxxhz/learnflow-server:latest
    container_name: learnflow-relay
    restart: unless-stopped
    pull_policy: always # 核心：启动/重启时自动拉取最新前后端一体化镜像
    ports:
      - "8421:8421"
    environment:
      - SERVER_PORT=8421
      - RELAY_SERVER_TOKEN=your_secure_token_here # 访问密码，留空则免密开放
      - RELAY_AUTH_REQUIRED=true
      - AI_MODE=auto                              # 智能模式：本地在线走本地，离线走云端
      - SERVER_LLM_BASE_URL=https://api.deepseek.com/v1 # 云端内置大模型
      - SERVER_LLM_API_KEY=sk-xxxx
      - SERVER_LLM_MODEL=deepseek-chat
    volumes:
      - ./data:/app/data                          # 持久化存储 SQLite 数据库与讲义缓存
      - /var/run/docker.sock:/var/run/docker.sock # 挂载后支持在网页端一键在线热更新
```

#### 2. 启动服务
```bash
docker compose up -d
```
启动后直接用手机/平板或电脑浏览器打开 `http://<你的VPS_IP>:8421` 即可体验纯 Web 学习！

### 方式三：从源码运行
依赖环境：Python 3.11+（使用 [uv](https://docs.astral.sh/uv/) 管理）与 Node.js 18+（构建前端）：

```bash
# 1. 构建前端（产物输出至 backend/app/static）
cd frontend && npm install && npm run build && cd ..

# 2. 启动服务（首次会自动 uv sync 安装依赖并初始化数据库）
cd backend && uv run python -m app.main
```

启动后浏览器会自动打开 `http://127.0.0.1:8420`。

## 模型配置

打开客户端「设置」页配置大语言模型：
- **标准协议**：兼容所有 OpenAI 规范 API（Base URL、API Key 与模型名称，支持一键点击「测试连接」）；
- **常用预设**：内置智谱 GLM、DeepSeek、OpenAI、Moonshot、Ollama、Gemini 等一键配置预设；
- **场景分工**：支持为「通用生成」、「对话问答」与「后台轻任务」单独指定不同模型；
- **云端大模型在线修改**：支持在 Web 端与桌面端设置页直接修改远端 VPS 的大模型 API，并持久化保存至服务端。

## 局域网访问与 PWA

- **局域网访问**：在设置页「局域网访问」中直接开启开关，控制台与设置页均会展示本机局域网访问链接及安全访问令牌（Token）；平板或手机连入同一 Wi-Fi 后即可在浏览器中使用。
- **PWA 桌面化体验**：移动端或平板浏览器访问局域网或 VPS 地址时，可点击浏览器菜单「添加到主屏幕」或「安装应用」，获得全屏无边框的独立 Native 体验，离线资源由内置 Service Worker 自动托管。
- **远程访问**：在异地网络下亦可配合 [Tailscale](https://tailscale.com/) 使用，享受端到端加密访问。

## 版本更新与在线管理

- **桌面端自动更新**：客户端启动时自动静默检测 GitHub Releases，发现新版弹出更新提示，支持通过国内加速镜像极速下载与断点续更；
- **VPS 云端在线一键更新**：在设置页「云端服务端在线更新」卡片中，可一键检查新版并点击「🚀 立即在线更新服务端」，服务端自动在后台拉取最新 Docker 镜像并平滑重启，15 秒倒计时后网页自动刷新。

## 数据存储与备份

应用数据完全存储于本地，开箱自包含：
- **源码模式**：所有数据存放于 `backend/data/` 目录；
- **打包安装版**：数据存放于系统应用数据目录（Windows 下为 `%APPDATA%\com.learnflow.desktop\`）；
- **云端服务端模式**：数据持久化存放于挂载的 `./data/` 卷中（SQLite WAL 格式，讲义存放在 `data/courses/` Markdown 文件）；
- 设置页「数据与安全」提供一键 zip 备份与恢复（备份含题库与配置，恢复前自动校验压缩包完整性），也可直接复制数据目录完成迁移。

## 技术栈

- **后端**：Python 3.11+ / FastAPI / SQLAlchemy 2.0 (Async) / SQLite (WAL) / SymPy (代数化简与等价判题) / Matplotlib (矢量 SVG 绘图) / pypdfium2 (PDF 处理) / PyInstaller
- **前端**：React 18 / TypeScript / Vite / TailwindCSS / Lucide Icons
- **云端中转与容器**：Docker (Multi-stage Build) / Docker Compose / GitHub Packages (GHCR) / GitHub Actions / Watchtower / WebSocket 反向长连接隧道
- **解析与排版**：markdown-it / KaTeX / Shiki 代码高亮 / diff-match-patch (划线模糊容错重锚定)
- **桌面与移动端**：Tauri v2 (Rust) / NSIS / PWA (Service Worker + Web App Manifest)
- **AI 架构**：OpenAI 兼容协议客户端 / Server-Sent Events (SSE) 毫秒级打字机流式输出 / Agent Tool Calling 闭环 / 双算力平滑调度引擎
