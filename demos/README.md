# 示范课程（Demo）

两份可直接导入 LearnFlow 的示范 Markdown 课程，用于体验「导入自有文档」与「文档内代码运行」：

- `python-basics.md` — Python 基础语法：6 章 12 个代码块，全部用安装版内置的 Python 运行环境实测通过
- `cpp-basics.md` — C++ 基础语法：7 章 10 个代码块，标准 C++17 写法（本仓库构建机未装 g++，未做编译验证；安装 MinGW-w64 后即可一键运行）

## 导入方式

应用内「课程」页 → 导入 Markdown → 选择 `demos/` 下的文件 → 确认切章 → 导入。未配置 LLM 也能导入（只跳过知识点提取，配置后重新生成的课程才有复习卡）。

## 代码块约束（与沙箱一致）

- 限时 10 秒、内存上限 256MB、stdin 关闭（不要用 `input()`），全局串行执行
- Python 块以 `-I -B -X utf8` 隔离模式运行，仅标准库
- C++ 块以 `g++ -std=c++17 -O0` 编译运行，需要本机 g++ / clang++ 在 PATH 中
